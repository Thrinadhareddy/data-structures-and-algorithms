# Python Pattern Programs

A collection of **97 Python programs** that print star, number, alphabet, pyramid, diamond, hourglass, hollow, and other console patterns.

This README is based on the source code in this folder. Each entry uses a descriptive name that reflects what its `.py` file actually prints; it does not rely on generic labels such as “Pattern 1” or “Pattern 2”.

Run a file from this directory with Python 3:

```bash
python Pattern10.py
```

Most programs prompt for the number of rows (or the pattern size). Enter a positive integer when prompted. For alphabet patterns, the source uses `chr(64 + n)` or related expressions, so the intended examples generally use sizes up to 26.

## Notes

- The source files are preserved as supplied; this README documents their current behavior rather than changing their implementations.
- `Pattern4.py` and `Pattern5.py` currently implement the same repeated-letter square: each row repeats its letter without spaces.
- `Pattern66.py` and `Pattern66_1.py` are different files: `Pattern66.py` draws a centered star triangle, while `Pattern66_1.py` draws a centered triangle of repeated row numbers.
- Some files contain commented sample output. Descriptions above are derived from the active (uncommented) loops and print statements.
- Pattern names are descriptive labels for the shapes/logic, not claims that every variation has a single universally standardized name.
